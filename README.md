# Holescope — версия 0.1 (сбор данных)

Страница для iPhone, которая во время поездки пишет акселерометр, гироскоп и GPS, а вы отмечаете ямы,
люки, «лежачих» и рельсы. Это **не** готовое приложение: задача версии — собрать настоящие данные по
ташкентским дорогам, чтобы подобрать алгоритм определения ям до разработки Flutter-приложения.

Всё хранится на телефоне. На сервер ничего не отправляется.

## Что внутри

| Файл | Назначение |
|---|---|
| `public/index.html`, `style.css`, `app.js` | сама страница (без зависимостей и сборки) |
| `public/sw.js`, `manifest.webmanifest`, `icons/` | работа без интернета и установка на экран «Домой» |
| `analysis/analyze.py` | разбор записи на компьютере: статистика, график, подсказка по порогу |
| `ROADMAP.md` | выбор стека, этапы, риски |

## 1. Выложите страницу по HTTPS

iPhone отдаёт датчики движения **только** страницам по HTTPS. Через `file://` или обычный `http://`
по Wi-Fi ничего не заработает. Подойдёт любой бесплатный хостинг статики:

- **Netlify Drop** — перетащить папку `public` в окно, получить адрес `https://…`;
- **Firebase Hosting** — `firebase init hosting`, папка публикации `public`, затем `firebase deploy`;
- **GitHub Pages** — загрузить содержимое папки `public` в репозиторий и включить Pages.

Загружайте **только папку `public`**: в ней всё, что нужно сайту. Папки `analysis/` и файлы `*.md`
остаются у вас на компьютере.

## 2. Установите на iPhone

1. Откройте адрес в **Safari**.
2. «Поделиться» → «На экран “Домой”».
3. Откройте иконку «Holescope». При первом запуске разрешите «Движение и ориентация» и геолокацию.

## 3. Перед выездом

- Настройки → Экран и яркость → Автоблокировка → **Никогда**. Если экран погаснет, Safari перестаёт
  получать датчики и GPS, в записи появится дыра (приложение это отметит).
- Телефон закрепите в держателе или положите на панель, чтобы он **не двигался** относительно машины.
  Телефон в руке или кармане даёт непригодные данные. В настройках записи укажите автомобиль и положение.
- Зарядка включена: GPS и экран сажают батарею.
- Геолокация для Safari: «При использовании».

## 4. Запись

1. «Начать запись». Подождите, пока GPS покажет точность лучше ±20 м.
2. Едьте. Скорость и график толчков идут на экране; пунктир — порог автоопределения.
3. **Пассажир** нажимает «Яма / Люк / Лежачий / Рельсы» сразу после удара. «Отменить» убирает ошибочную отметку.
4. Едете один? Не нажимайте ничего за рулём. Приложение само запишет «авто-кандидатов»
   (звук и счётчик), а ямы потом найдём по графику вместе с GPS-координатами.
5. «Остановить запись» → «Поделиться» → Файлы / Telegram («Избранное») / AirDrop. Или «Скачать».

### Что собрать для первого анализа

- 3–5 разных маршрутов: хорошая дорога, плохая, с люками, с рельсами или стыками плит.
- От 30 отметок «Яма» и по 10 отметок других типов. Другие типы нужны, чтобы научиться
  отличать яму от люка и «лежачего».
- Разные скорости: 20–30, 50–60 км/ч. Одна и та же яма на разной скорости бьёт по-разному.
- Желательно ещё одна машина, если есть возможность. Подвески разные.

## 5. Разбор на компьютере

```
pip install pandas numpy matplotlib
python analysis/analyze.py pothole_2026-10-16_12-00-00.csv
```

Скрипт напишет, сколько данных собрано и есть ли в них разрывы, найдёт пик толчка у каждой отметки,
сравнит пики ям с фоновым шумом и подскажет порог. Рядом сохранится график `.png`.
Флаги: `--show` (окно с графиком), `--from 120 --to 180` (приблизить участок).

## Формат CSV

Первые строки с `#` — метаданные (автомобиль, положение телефона, порог, браузер). Дальше таблица:

| type | что это |
|---|---|
| `m` | отсчёт датчиков: `ax,ay,az` — ускорение с гравитацией (м/с²), `lx,ly,lz` — без гравитации, `rx,ry,rz` — вращение (°/с) |
| `g` | GPS-фикс: `lat, lon, gps_acc_m, speed_ms, heading_deg` |
| `k` | ваша отметка, `label` = `pothole / manhole / bump / rail` |
| `a` | авто-кандидат, `note` = пик толчка (м/с²) |
| `u` | отмена отметки, `note` = время отменённой |
| `v` | экран скрылся / появился — на этом участке данных нет |

`t_ms` — время в мс (Unix). У Safari первый отсчёт датчика иногда пустой — анализатор его пропускает.

## Ограничения версии 0.1

- Работает только при включённом экране (iOS не даёт веб-страницам читать датчики в фоне).
  Именно поэтому следующий этап — нативное приложение на Flutter.
- Автоопределение — простой порог, он нужен для демонстрации и сравнения с вашими отметками,
  а не как готовый алгоритм.
- Положение телефона должно быть стабильным. Поворот телефона во время записи портит оценку гравитации
  на пару секунд.
- Страница не умеет отправлять данные на сервер — это сознательно: сначала проверяем, видны ли ямы в датчиках.

## Конфиденциальность

В файле есть координаты и время ваших поездок. Делитесь им осознанно. Когда появится сервер, он будет
хранить точки событий, а не маршруты.

## Если меняете файлы

Страница кэшируется для работы без интернета. После правок поднимите `CACHE` в `public/sw.js`
(например, `pothole-logger-v3`), иначе телефон будет показывать старую версию до второго запуска.
